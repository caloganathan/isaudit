# Brand assets

Components reference these exact paths:

- `jcss-logo.png` — JCSS wordmark (orange, grey "Delivering Transparency" tagline)
- `jcss-logo-white.png` — knockout/white version used on the dark theme
- `loganathan.jpg` — headshot, CA Loganathan Anandan (pending — initials
  monogram renders until this file is added)
- `vinodhan.jpg` — headshot, Vinodhan J (pending — initials monogram renders
  until this file is added)

The two logo PNGs currently in this folder are high-fidelity vector
recreations of the official wordmark (Tinos/Times serif, JCSS Orange
#E9531E, JCSS Grey #6E6F72), generated because the original binary could
not be transferred into the build environment. Overwriting them with the
official PNGs — same filenames — needs no code changes, same for the two
headshot JPGs.
