# Brand assets

Drop the supplied assets into this folder with these exact filenames —
components already reference these paths and fall back to a styled text
wordmark / initials monogram until the files exist:

- `jcss-logo.png` — JCSS wordmark (orange, with grey "Delivering Transparency" tagline)
- `jcss-logo-white.png` — optional knockout/white version for dark surfaces
- `loganathan.jpg` — headshot, CA Loganathan Anandan
- `vinodhan.jpg` — headshot, Vinodhan J

No code changes are needed after dropping the files in.
